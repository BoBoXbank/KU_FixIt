# 🚀 Utility Issue Reporting System (Flask Web App)

[cite_start]โปรเจกต์เว็บแอปพลิเคชันสำหรับรายงานปัญหาอุปโภคบริโภคในมหาวิทยาลัย พัฒนาด้วย Flask และเชื่อมต่อกับฐานข้อมูล TiDB Cloud (AWS) [cite: 1]

## 📋 ฟีเจอร์หลัก
* **ระบบสมาชิก:** สมัครสมาชิก, ล็อกอิน และรีเซ็ตรหัสผ่านด้วยคำถามความปลอดภัย
* **ระบบรายงาน:** ผู้ใช้สามารถแจ้งเรื่อง ระบุสถานที่ และรายละเอียดปัญหาได้
* **ระบบ Admin:** จัดการสถานะรายงาน, แต่งตั้ง/ปลดสิทธิ์แอดมิน และจัดการรายชื่อผู้ใช้งาน
* [cite_start]**ความปลอดภัย:** แฮชรหัสผ่าน (Password Hashing) และเชื่อมต่อฐานข้อมูลผ่าน SSL [cite: 4]

## 🛠 ขั้นตอนการติดตั้ง (Setup Instructions)

### 1. เตรียมสภาพแวดล้อม (Virtual Environment)
แนะนำให้สร้างระบบจำลองเพื่อไม่ให้ Library ตีกับโปรเจกต์อื่น:
```bash
# สร้าง venv
python -m venv .venv

# เปิดใช้งาน (Windows)
.venv\Scripts\activate

# เปิดใช้งาน (macOS/Linux)
source .venv/bin/activate
